# F3 a F9 — nível de fase

Detalhadas em itens quando a fase começar.

## F3 — Migração Agno 3.x
Bump para 3.1.x só no `AgnoRuntime` (renomes: `enable_user_memories`→`update_memory_on_run`, `Knowledge.add_content`→`insert`, `JWTMiddleware(verification_keys)`, `mcp_server=`); `MigrationManager` para a tabela `agno_runs`; testes de contrato na matriz 2.5.8 × 3.1.x durante a transição; runbook com backup do Mongo; **nunca** rodar `cleanup_legacy_runs_column` no mesmo release. Conferir o controle de telemetria dos evals no Agno 3.x (no 2.5.8 a rota `/eval-runs` cria evals com `telemetry=True` que ignoram `AGNO_TELEMETRY`; resíduo do F1-03).

## F4 — Tools + MCP cliente
F4-01 `ToolSource` + HTTP endurecido (guarda SSRF com allowlist de esquema/host, bloqueio de IP privado/link-local/metadata com re-checagem de DNS, encoding de path params (o F1-05 já faz `quote(safe="")` e recusa `.`/`..`; falta revisar o resto da rota), `AsyncClient` compartilhado, limites, retry com jitter, erro sanitizado, headers secretos por referência). F4-02 MCP cliente só HTTP (guarda SSRF, allowlist de tools, hash de schema fixado, ciclo de vida no lifespan, extra `mcp`). F4-03 log de auditoria de tool calls.

## F5 — Segurança e governança
F5-01 `AuthService` (api_key com escopos + JWT) substitui a auth da F1-04. F5-02 identidade do principal em REST/AG-UI/MCP; escopos por agente. Inclui (achado do QA no F1-06): com a chave run, `GET/POST /memories?user_id=` e `GET /sessions/{id}/runs` do AgentOS leem e gravam dados de qualquer `user_id` (o `user_id` é declarado pelo cliente, não amarrado à credencial); o run idem. F5-03 rate limit por principal + limites de corpo/tempo. F5-04 guardrails por agente (PII, prompt injection, moderação). F5-05 segredos só por referência + migração de `headers` em texto + TLS no OTLP + trocar o account token do Codacy na CI por `CODACY_PROJECT_TOKEN` (exige criar o secret). F5-06 supply chain na CI (pip-audit, bandit, gitleaks, SBOM, Dependabot) + suíte de segurança por categoria OWASP Agentic ASI.

## F6 — Protocolos
F6-01 AG-UI 1.0 (versão mínima do Agno conferida no pacote). F6-02 AgentProtocol (adaptadores via plugin + allowlist; política na borda ASGI, pois os adaptadores não herdam guardrails). F6-03 servidor MCP (`/mcp` stateless, auth da F5, allowlist de agentes expostos, `allowed_hosts`).

## F7 — RAG plugável
F7-01 `VectorStore` (Mongo `$vectorSearch` + Chroma; Chroma é o default local; reindex da coleção legada). F7-02 registry de `DocumentParser` (texto/markdown + PDF). F7-03 `RetrievalStrategy` (semantic e hierarchical como tool tipada). F7-04 estratégia hybrid (BM25 + vetor, RRF) + evals de recuperação (recall@k, MRR). Calibrar com essas evals o limiar mínimo de score da busca hierárquica (hoje 0.3, estimado no F1-07) e torná-lo configurável por `RagConfig`; árvore hierárquica (`document_tree`) passa a ser por agente/embedder.

## F8 — Observabilidade e Evals
Tradução OpenInference → `gen_ai.*`; spans de tool/retrieval; métricas de token/custo; captura de conteúdo desligada por padrão; labels de métrica com cardinalidade limitada (inclui o gauge `agents_active`, que ainda usa o id do path antes do roteamento; métricas de runs via AG-UI); correlation id; evals determinísticas (modelo scriptado) como gate; evals ao vivo só como `live`.

## F9 — Execução durável
`QueueConfig(durable=True)` (exige `db=`), runs em background com cancelamento/deduplicação, runbook, teste de caos (processo morto no meio do run).
